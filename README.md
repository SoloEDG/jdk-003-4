# 余烬行旅

安装依赖：`npm install`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose -p pinru-jdk003-high-1113 up --build -d`，访问 http://localhost:18023。

停止：`docker compose -p pinru-jdk003-high-1113 down`。

## 自定义远征规则包

侧边栏「06 远征规则」是规则编辑器：

- **草稿**：可编辑地区节点（名称、地区、类型、深度、威胁/好感/稀缺增量）、节点连接、每种战斗/精英/首领遭遇的敌人（名称、生命、攻击、意图倍率序列、力量、荆棘、中毒、护盾节奏、金币）、战斗节点奖励池、商店库存与标价、起始牌组。卡牌仍从现有卡库选择。
- **即时预览**：改动某个节点后，遭遇预览（含逐回合意图）与可售/可奖励卡列表立即按草稿实际配置刷新；商店还显示按该节点实际路径影响计算后的实付价格。
- **发布即冻结**：点击「发布并冻结版本」会保存一份深拷贝为不可变版本，之后的草稿修改不会影响已发布版本。
- **试跑与正式开局**：都从已发布版本启动，并各自写入独立存档槽（正式与试跑互不影响）。正在进行的远征引用启动时冻结的规则快照，草稿改动不会改变它。
- **发布校验**：出现不可达终点、循环连接、未知卡牌、空敌人（或无起点/悬空连接）时禁止发布，并在问题列表中标注关联节点 id；点击左侧节点即可定位。
- **分享与导入**：可导出草稿或已发布版本为 JSON 分享文本，也可把分享文本作为草稿打开或直接登记为新版本；导入会先归一化再校验，不合格的版本会被拒绝登记。
- **旧存档恢复**：存档内含启动时冻结的规则包，即使该版本已从规则库移除，恢复后仍按原版本运行。早期无规则快照的存档按经典规则继续。

规则包结构（`SharedRulePack`）为 `{ format: "ember-path-rulepack", schema: 1, pack, versionLabel? }`，`pack` 包含 `starterDeck`、`nodes`（节点各自带 `enemy` / `rewards` / `stock`）。
